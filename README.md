# LASSO Cell Tracking Analysis
These codes are for analyzing convective cell tracking outputs applied to LASSO-CACTI simulations.

## Directories
* **src**  
Codes to process data to get statistics
* **tracking**  
Scripts and templates to make cell tracking configuration files
* **regrid**  
Scripts to regrid (coarsen) LASSO high-resolution outputs to low-resolution
* **notebooks**  
Jupyter notebooks for analysis and plotting
