USAGE WORKFLOW

Step 1: Test Single File
-------------------------
$ cd /ccsopen/home/zhe1feng1/program/lasso/cellgrowth/regrid
$ python test_regrid_single.py
⏱  ~3-5 minutes

Step 2: Test Batch (1 hour)
----------------------------
$ python regrid_lasso_batch.py \
    --case-date 20190123 \
    --start-hour 0 \
    --end-hour 1 \
    --file-type methamsl \
    --subset d4 \
    --n-workers 6 \
    --regrid-ratio 25
⏱  ~6-10 minutes

Step 3: Submit Job Array (1 case)
----------------------------------
$ mkdir -p logs
$ sbatch --export=CASE_DATE=20190123,FILE_TYPE=methamsl,SUBSET=d4 slurm_regrid.sh
⏱  ~1.5-2 hours (12 hours × 12 files each)

Step 4: Submit All Cases
-------------------------
$ bash submit_all_cases.sh
⏱  ~2 hours total (if nodes available)
