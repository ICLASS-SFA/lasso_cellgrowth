            PROCESSING TIMELINE
            ===================

Sequential (1 worker):
─────────────────────────────────────────────────────────────────
10,368 files × 5 min = 51,840 min = 864 hours = 36 days
─────────────────────────────────────────────────────────────────

Parallel (6 workers per node):
─────────────────────────────────────────────────────────────────
10,368 files ÷ 6 workers = 1,728 files per worker
1,728 × 5 min = 8,640 min = 144 hours = 6 days
─────────────────────────────────────────────────────────────────

Parallel (72 nodes simultaneously):
─────────────────────────────────────────────────────────────────
72 nodes × 6 workers = 432 parallel files
10,368 files ÷ 432 ≈ 24 batches
24 batches × 5 min = 120 min = 2 hours ⭐
─────────────────────────────────────────────────────────────────

        OPTIMIZATION FEATURES
        =====================

Memory Optimization:
✓ Single-pass processing (no intermediate arrays)
✓ Immediate garbage collection
✓ float32 when possible (halves memory)
✓ NaN handling without extra arrays

Speed Optimization:
✓ uniform_filter (2-5x faster than convolve)
✓ Parallel processing with Dask
✓ Batch file I/O
✓ Efficient coordinate subsampling

Code Optimization:
✓ Eliminated nested loops
✓ Single loop for all variables
✓ Clear separation of concerns
✓ Proper error handling

HPC Optimization:
✓ Job arrays (reduces scheduler overhead)
✓ 1-hour chunks (good failure granularity)
✓ Automatic retry capability
✓ Independent tasks (no dependencies)
