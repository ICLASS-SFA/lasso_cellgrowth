IMPLEMENTATION FILES (Production Code)
================================================================================

1. regrid_func.py                                               [12 KB]
   Core regridding functions
   
   Functions:
   • coarsen_variable_filter()       - Generic variable coarsening
   • coarsen_reflectivity_filter()   - Reflectivity with dBZ conversion
   • regrid_file()                   - Main file processing function
   • create_semi_symmetric_array()   - Coordinate helper
   
   Key Features:
   - Memory efficient (single-pass processing)
   - Handles NaN values properly
   - Preserves variable and coordinate attributes
   - Warning suppression for expected reflectivity edge cases

2. regrid_lasso_batch.py                                        [8.7 KB]
   Batch processing with Dask parallelization
   
   Functions:
   • get_files_in_timewindow()       - File discovery by timestamp
   • process_single_file()           - Wrapper with error handling
   • process_batch_with_dask()       - Parallel Dask processing
   • main()                          - Command-line interface
   
   Usage:
   python regrid_lasso_batch.py --case-date YYYYMMDD --start-hour H \
       --end-hour H --file-type TYPE --subset DOMAIN --n-workers N

3. test_regrid_single.py                                        [2.1 KB]
   Simple test script for single file
   
   Purpose: Test regridding on one file before batch processing
   Usage: python test_regrid_single.py
   Edit: Change input file, regrid_ratio, var_names for testing

HPC JOB SCRIPTS
================================================================================

4. slurm_regrid.sh                                              [2.3 KB]
   SLURM job array script (1-hour chunks)
   
   Features:
   - Processes 12 tasks per case (one per hour)
   - Configurable via environment variables
   - Automatic log file creation
   - Error checking and reporting
   
   Usage:
   sbatch --export=CASE_DATE=20190123,FILE_TYPE=methamsl,SUBSET=d4 \
       slurm_regrid.sh
   
   Modify:
   - #SBATCH --account=YourAccount
   - #SBATCH --mem=512GB (for high-memory nodes)
   - #SBATCH --array=0-5 (for 2-hour chunks)
   - Python environment path

5. submit_all_cases.sh                                          [2.2 KB]
   Master submission script
   
   Features:
   - Submits all cases automatically
   - Handles 18 cases × 2 file types × 2 subsets = 72 job arrays
   - Provides submission summary
   
   Usage:
   bash submit_all_cases.sh
   
   Modify:
   - CASES array (add all 18 case dates)
   - FILE_TYPES (if different types needed)
   - SUBSETS (if different domains needed)
   - REGRID_RATIO, N_WORKERS

Testing Workflow:
-----------------
1. test_regrid_single.py              → Single file (5 min)
2. regrid_lasso_batch.py (1 hour)     → Batch test (10 min)
3. slurm_regrid.sh (one case)         → Job array test (2 hours)

Monitoring Workflow:
--------------------
1. squeue -u $USER                    → Check job status
2. tail -f logs/regrid_*.out          → Watch progress
3. grep -i error logs/*.err           → Check for errors
4. ls output_dir/*.nc | wc -l         → Count outputs

QUICK COMMAND REFERENCE
================================================================================

Test:
  python test_regrid_single.py

Batch (interactive):
  python regrid_lasso_batch.py --case-date 20190123 --start-hour 0 \
      --end-hour 1 --file-type methamsl --subset d4 --n-workers 6

Submit one case:
  sbatch --export=CASE_DATE=20190123,FILE_TYPE=methamsl,SUBSET=d4 \
      slurm_regrid.sh

Submit all:
  bash submit_all_cases.sh

Monitor:
  squeue -u $USER
  watch -n 2 'squeue -u $USER'
  tail -f logs/regrid_*.out

Check results:
  ls /path/to/output/*.nc | wc -l
  grep -c "Successfully wrote" logs/*.out
