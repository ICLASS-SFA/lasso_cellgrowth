TROUBLESHOOTING CHECKLIST
========================================

If test_regrid_single.py fails:
□ Check input file exists
□ Check output directory writable
□ Check Python packages installed
□ Check for error messages in output

If batch processing fails:
□ Check file timestamp parsing
□ Check Dask workers start successfully
□ Reduce n_workers if memory errors
□ Check individual file with test script

If job submission fails:
□ Check SLURM account name
□ Check node availability (sinfo)
□ Check disk quota (quota -s)
□ Verify script syntax (bash -n slurm_regrid.sh)

If jobs are pending:
□ Check queue status (squeue)
□ Check priority (sprio)
□ May need to wait for resources
□ Consider submitting fewer jobs at once

If jobs fail during execution:
□ Check log files for errors
□ Verify input files not corrupted
□ Check memory usage (seff <JOB_ID>)
□ Resubmit specific failed tasks
